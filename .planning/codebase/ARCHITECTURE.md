# UIC Website — Codebase Architecture Map

> Generated by `/gsd-onboard --fast` on 2026-09-14

## 1. Overview

The **Unstop Igniters Club (UIC) Website** is a full-stack, single-page web application for a college student club. It manages events, team showcase, photo gallery, member dashboards, certificate issuance/verification, attendance tracking, and admin operations — all backed by Supabase (PostgreSQL + Auth + Storage).

| Dimension         | Value                                                     |
| ----------------- | --------------------------------------------------------- |
| **Language**       | TypeScript (strict)                                      |
| **Framework**      | React 18 (Vite + SWC)                                   |
| **UI Library**     | shadcn/ui (Radix primitives) + Tailwind CSS 3            |
| **State Mgmt**     | React Query v5 (`@tanstack/react-query`)                 |
| **Routing**        | React Router DOM v6                                      |
| **Backend**        | Supabase (PostgreSQL, Auth, Storage, RPC, RLS)           |
| **Auth Provider**  | Google OAuth via Supabase Auth                           |
| **Animations**     | Framer Motion + Tailwind keyframes                       |
| **Analytics**      | Vercel Web Analytics                                     |
| **SEO**            | react-helmet-async + JSON-LD                             |
| **Deployment**     | Vercel (SPA rewrite via `vercel.json`)                   |
| **Dev port**       | `localhost:8080`                                         |

## 6. Authentication & Authorization

- **Provider**: Google OAuth only (via Supabase Auth)
- **Auth flow**: `useAuth` hook wraps `supabase.auth.onAuthStateChange`
  - Deduplicates `SIGNED_IN` events on tab-focus token refresh
  - Redirects to `/dashboard` on genuine first sign-in
- **RBAC**: `user_roles` table with `role` enum (`super_admin`, `admin`, `member`)
  - `useRequireAdmin` hook guards the admin panel
  - `ProtectedAdminRoute` component wraps `/admin` route
- **Super Admin**: Protected at database level — cannot be demoted via UI
  - `config/superAdmin.ts` holds the protected account ID

## 7. Key Design Patterns

1. **Domain types decoupled from DB**: `src/types/index.ts` defines UI-friendly interfaces; services map raw Supabase rows to these
2. **React Query as server state**: All data fetching uses `useQuery` / `useMutation` with 5-minute stale time
3. **shadcn/ui as component library**: 49 Radix-based primitives in `components/ui/`, untouched from generation
4. **SEO-first**: Every page uses the `<Seo>` component with `react-helmet-async`; JSON-LD structured data via `<JsonLd>`
5. **Settings as global context**: `SettingsContext` loads `site_settings` once and shares it across Navbar, Footer, Hero, SEO
6. **QR certificate verification**: Camera scanning via `jsqr` library + `useQrScanner` hook; public verification through `verify_certificate()` RPC (SECURITY DEFINER)
7. **Monolithic admin page**: `Admin.tsx` (82KB) contains all admin tabs inline — this is the largest single file

## 9. Notable Observations

| # | Observation | Impact |
|---|-------------|--------|
| 1 | `Admin.tsx` is 82KB / ~2000+ lines | Hard to maintain; candidate for splitting |
| 2 | No test files anywhere | Zero test coverage |
| 3 | No CI/CD pipeline config | Manual deployments only |
| 4 | `lovable-tagger` in devDependencies | Indicates project was scaffolded with Lovable.dev |
| 5 | `supabase/types.ts` is auto-generated (24KB) | Must be regenerated after schema changes |
| 6 | All 49 shadcn/ui components imported | Many may be unused |
| 7 | No error boundary components | Unhandled errors crash the whole app |
| 8 | `certifiedStudents.ts` in `data/` has static data | Duplicates DB table purpose |
