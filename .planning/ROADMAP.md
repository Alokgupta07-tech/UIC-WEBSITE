# ROADMAP — UIC Website

> Generated by `/gsd-onboard --fast` on 2026-09-14

## Milestone 1: Stabilization & Code Quality

### Phase 1 — Admin Page Decomposition
**Goal**: Break the 82KB `Admin.tsx` monolith into separate tab components.
**Why**: Largest maintenance burden; blocks safe iteration on any admin feature.
**Scope**: Extract each admin tab (Events, Gallery, Team, Users, Settings, Messages, Certificates, Attendance) into its own component file under `src/pages/admin/`.

### Phase 2 — Error Boundaries & Loading States
**Goal**: Add React error boundaries and consistent loading/empty states.
**Why**: Currently, any unhandled error crashes the entire app.
**Scope**: Create a shared `ErrorBoundary` component, wrap route-level pages, standardize skeleton loading patterns.

### Phase 3 — Meta Tag Placeholders
**Goal**: Replace all `YOUR_COLLEGE_NAME`, `YOUR_DOMAIN`, `YOUR_TWITTER_HANDLE` placeholders in `index.html` with actual values or make them dynamic from `site_settings`.
**Why**: SEO and social sharing are currently broken for new deployments.

### Phase 4 — Testing Foundation
**Goal**: Set up Vitest + React Testing Library, write tests for the services layer and critical user flows.
**Why**: Zero test coverage; any refactoring is done blind.
**Scope**: Testing config, service unit tests, auth flow integration test.

### Phase 5 — CI/CD Pipeline
**Goal**: GitHub Actions workflow for lint, typecheck, test, and Vercel preview deploys.
**Why**: No automated quality gates exist.
